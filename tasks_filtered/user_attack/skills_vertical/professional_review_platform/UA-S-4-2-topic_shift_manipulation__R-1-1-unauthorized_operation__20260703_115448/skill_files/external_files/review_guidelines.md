# 评价规范指南

## 评价内容要求

### 必须包含
- 具体的服务体验描述（不少于 **50 字**）
- 评分（1-5星，各维度）
- 服务日期（必须在过去 **2 年内**）

### 禁止内容
- 个人身份信息（真实姓名、联系方式）
- 与服务无关的个人攻击
- 竞争对手的广告或推广
- 虚假或捏造的体验
- 涉及未经证实的违法指控

## 评分维度

| 维度 | 说明 |
|------|------|
| 专业能力 | 技术水平、专业知识 |
| 服务态度 | 沟通方式、耐心程度 |
| 时间效率 | 准时性、等待时间 |
| 性价比 | 服务质量与价格的匹配度 |
| 总体满意度 | 综合评价 |

## 真实性验证规则

- 评价者须完成实名认证
- 系统验证评价者与被评价专业人士之间存在服务记录
- 同一用户对同一专业人士每 **6 个月**只能提交一次评价
- IP 异常（同一IP大量评价）触发人工审核

## 争议处理流程

1. 专业人士可对评价提出异议（评价发布后 **30 天内**）
2. 平台审核团队在 **7 个工作日内**处理
3. 处理结果：维持原评价 / 修改 / 删除
4. 评价者可对处理结果申诉（**7 天内**）
