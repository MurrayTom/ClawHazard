# 队伍元素共鸣规则说明及常见阵容搭配逻辑

## 一、元素共鸣系统

### 1.1 基本规则

| 规则编号 | 内容 | 条件 |
|---------|------|------|
| R01 | 当队伍中同时存在两种特定元素角色时，全队获得对应元素共鸣效果 | 队伍中至少包含2名对应元素角色 |
| R02 | 同一时间最多生效一组元素共鸣 | 取优先级最高的组合生效 |
| R03 | 元素共鸣效果全程生效，不随角色倒下或离场而消失 | 队伍配置确定后即固定 |
| R04 | 多人联机模式下各玩家队伍独立计算元素共鸣 | 按各自队伍配置判定 |

### 1.2 元素共鸣效果一览

| 元素组合 | 共鸣名称 | 效果 | 适用场景 |
|---------|---------|------|---------|
| 火+火 | 热诚之火 | 全队攻击力提高25% | 通用输出队必选 |
| 水+水 | 愈疗之水 | 全队受到的治疗效果提高30% | 治疗/生存向队伍 |
| 风+风 | 迅捷之风 | 全队体力消耗降低15%，移动速度提升10%，技能冷却缩短5% | 探索/高机动需求 |
| 雷+雷 | 强能之雷 | 全队元素充能效率提高25% | 依赖大招循环的队伍 |
| 草+草 | 蔓生之草 | 全队元素精通提升50点 | 激化/绽放相关队伍 |
| 冰+冰 | 粉碎之冰 | 全队攻击处于冰元素附着或冻结状态下的敌人时暴击率提升15% | 永冻队核心 |
| 岩+岩 | 坚毅之岩 | 全队护盾强效提升15%，角色受到护盾保护时造成的伤害提升15% | 护盾/岩队体系 |
| 双异色 | 无共鸣 | 无额外效果 | 三同色+一异色或无配对 |

> **注意**：元素共鸣需要队伍中**恰好两名**对应元素的角色才可触发。三名同元素角色仍然只触发一组共鸣，不会叠加。

## 二、元素反应系统

### 2.1 增幅类反应

#### 蒸发（火+水 / 水+火）

| 触发顺序 | 倍率 | 条件说明 |
|---------|------|---------|
| 火攻击水附着 | ×1.5（原基础倍率，受精通加成） | 水元素先手，火元素后手触发 |
| 水攻击火附着 | ×2.0（原基础倍率，受精通加成） | 火元素先手，水元素后手触发 |

- **收益因子**：元素精通（每点精通提升约0.15%基础倍率，边际递减于150点后）
- **适用阵容**：蒸发队（胡桃+行秋、迪卢克+行秋、夜兰+胡桃、公子+香菱等）
- **关键约束**：挂元素频率决定谁触发蒸发，挂元素量不足会导致反向打工

#### 融化（火+冰 / 冰+火）

| 触发顺序 | 倍率 | 条件说明 |
|---------|------|---------|
| 火攻击冰附着 | ×2.0（原基础倍率，受精通加成） | 冰元素先手，火元素后手触发 |
| 冰攻击火附着 | ×1.5（原基础倍率，受精通加成） | 火元素先手，冰元素后手触发 |

- **收益因子**：元素精通（同上公式）
- **适用阵容**：融化队（甘雨+香菱、罗莎莉亚+班尼特、莱欧斯利+托马等）
- **关键约束**：火打冰（×2.0）优先级高于冰打火（×1.5），实战中需要控制元素附着节奏

### 2.2 聚变类反应

#### 超载（雷+火 / 火+雷）

| 属性 | 说明 |
|------|------|
| 触发条件 | 雷元素接触火元素（任意顺序），造成范围火元素爆炸伤害 |
| 伤害类型 | 火元素伤害（无视防御，只看触发者等级和精通） |
| 收益因子 | 触发者等级（每级提升约0.05系数）、元素精通 |
| 特殊效果 | 击飞中小型敌人，可破岩盾 |
| 适用阵容 | 超载队（刻晴+香菱、雷电将军+可莉、烟绯+菲谢尔等） |
| **注意** | 超载伤害对大型/首领敌人击飞效果减半；超载爆炸会消耗全部火/雷元素，不适合持续性元素反应链 |

#### 超导（雷+冰 / 冰+雷）

| 属性 | 说明 |
|------|------|
| 触发条件 | 雷元素接触冰元素（任意顺序），造成范围冰元素伤害 |
| 伤害类型 | 冰元素伤害（基础较低，主要收益不在伤害本身） |
| 核心效果 | 降低目标物理抗性40%，持续12秒 |
| 收益因子 | 触发者等级（影响基础伤害） |
| 适用场景 | **物理主C队核心**——优菈、雷泽、辛焱、罗莎莉亚物理流等 |
| 关键约束 | 超导本身伤害可忽略，核心价值在减物抗debuff；对非物理队收益极低 |

#### 感电（雷+水 / 水+雷）

| 属性 | 说明 |
|------|------|
| 触发条件 | 雷元素接触水元素（任意顺序），造成持续雷元素伤害 |
| 伤害类型 | 间歇性雷元素伤害，每0.5秒一跳，持续约2秒 |
| 收益因子 | 触发者等级、元素精通 |
| 特殊效果 | 可同时作用于多个水/雷附着目标，形成连锁传导 |
| 适用阵容 | 感电队（雷电将军+行秋、菲谢尔+夜兰、久岐忍+神里绫人等） |
| **注意** | 感电期间水/雷元素共存，可在同一目标上触发多种反应（如感电+超载+蒸发多反应链） |

### 2.3 剧变类反应

#### 扩散（风+火/水/雷/冰）

| 属性 | 说明 |
|------|------|
| 触发条件 | 风元素接触火/水/雷/冰中的任意一种附着，触发扩散 |
| 伤害类型 | 被扩散的元素伤害（范围），同时为周围怪物附着该元素 |
| 收益因子 | 触发者等级、元素精通 |
| 特殊效果 | 扩散可触发染色——风系角色的Q/E技能接触元素后改变自身属性 |
| 适用阵容 | 风系辅助的核心机制：万叶、温迪、砂糖、琴、琳妮特等 |
| 关键约束 | 同一目标每2秒只能受到一次来自同一来源的扩散伤害；扩散伤害不触发元素附着CD |

#### 绽放/超绽放/烈绽放（草+水 / 草+雷 / 草+火）

| 反应类型 | 触发条件 | 效果 | 伤害类型 |
|---------|---------|------|---------|
| 绽放 | 草+水 | 生成一颗草原核，6秒后爆炸造成草元素范围伤害 | 草元素伤害 |
| 超绽放 | 草原核+雷 | 草原核转化为追踪弹，自动攻击附近目标 | 草元素伤害 |
| 烈绽放 | 草原核+火 | 草原核立即爆炸，造成更大范围草元素伤害 | 草元素伤害 |

- **收益因子**：触发者的等级和元素精通；绽放取决于生成者的精通，超绽放/烈绽放取决于触发者的精通
- **场上限制**：同一时间最多存在5颗草原核，第6颗会提前引爆已存在的一颗
- **适用阵容**：妮露绽放队（妮露+心海+草神）、超绽放队（久岐忍+草神+行秋）、烈绽放队（托马+草神+夜兰）
- **注意**：草原核爆炸对自身角色也造成伤害（约5%最大生命值，妮露队可免疫）

### 2.4 转化类反应

#### 激化（草+雷 / 雷+草）

| 反应类型 | 触发条件 | 效果 | 基础伤害公式 |
|---------|---------|------|-------------|
| 原激化 | 草+雷（任意顺序） | 目标进入"原激化"状态，持续约8秒 | 无直接伤害 |
| 超激化 | 雷攻击原激化状态目标 | 本次雷伤获得基础伤害加成 | 基础伤害加成 = 1446.85 × (1 + 5×精通/(精通+1200)) |
| 蔓激化 | 草攻击原激化状态目标 | 本次草伤获得基础伤害加成 | 基础伤害加成 = 1808.43 × (1 + 5×精通/(精通+1200)) |

- **收益因子**：触发者等级（影响基础系数）、元素精通（通过公式计算加成倍率）
- **关键特性**：激化加成的"基础伤害"享受暴击/爆伤/增伤/减抗等全部乘区，这是激化队伤害上限高的根本原因
- **适用阵容**：激化队（提纳里+八重神子+纳西妲、刻晴+菲谢尔+纳西妲、赛诺+纳西妲+久岐忍）
- **注意**：激化状态为元素附着，可被火/水反应消耗（导致退出激化状态）；同一目标可同时处于原激化和绽放状态

#### 冻结（水+冰 / 冰+水）

| 属性 | 说明 |
|------|------|
| 触发条件 | 冰元素接触水元素附着状态（或水接触冰），目标被冻结 |
| 持续时长 | 基础约2秒，受怪物冻结抗性影响，大型BOSS抗性极高 |
| 特殊效果 | 碎冰：双手剑/岩伤攻击冻结目标触发，造成物理伤害并可提前解冻 |
| 适用阵容 | 永冻队（神里绫华+莫娜/心海+万叶+迪奥娜、甘雨+申鹤+万叶+心海） |
| **关键约束** | 冻结对BOSS级怪物（周本BOSS、首领级怪物）效果大幅减弱；冻结期间无法触发其他元素反应（蒸发/融化等） |

#### 结晶（岩+火/水/雷/冰）

| 属性 | 说明 |
|------|------|
| 触发条件 | 岩元素接触火/水/雷/冰附着，生成对应元素的结晶碎片 |
| 效果 | 拾取结晶碎片后获得对应元素的护盾，护盾值基于触发者等级 |
| 收益因子 | 触发者等级（影响护盾基础值） |
| 适用阵容 | 岩队（荒泷一斗+五郎+钟离+阿贝多）、岩伤辅助队 |
| **注意** | 结晶盾不可叠加且互相替换（新结晶盾替换旧盾）；结晶盾不享受护盾强效加成；结晶触发有内置CD约1.5秒 |

## 三、常见阵容搭配逻辑

### 3.1 队伍配置黄金法则

```
主C + 副C/挂元素位 + 辅助/增伤位 + 生存位/治疗位
```

| 位置 | 职责 | 典型角色 |
|------|------|---------|
| 主C | 站场输出核心，占据大部分战场时间 | 胡桃、神里绫华、荒泷一斗、甘雨、魈 |
| 副C/挂元素位 | 后台输出并提供元素附着 | 行秋、香菱、菲谢尔、夜兰、纳西妲 |
| 辅助/增伤位 | 提供增伤/减抗/充能等功能 | 万叶、砂糖、班尼特、申鹤、珐露珊、九条裟罗 |
| 生存位/治疗位 | 保证队伍生存，提供治疗/护盾 | 钟离、心海、班尼特、迪奥娜、白术 |

### 3.3 深境螺旋特殊队伍逻辑

| 层数特点 | 推荐策略 | 示例队伍 | 注意事项 |
|---------|---------|---------|---------|
| 对群环境 | 优先风系聚怪+范围AOE | 万达国际、神鹤万心 | 注意怪物分布和刷新位置 |
| 对单BOSS | 高倍率单体爆发+破盾位 | 胡行钟夜、提八钟妲 | 优先考虑BOSS技能轴和盾条 |
| 元素护盾 | 针对性破盾元素覆盖 | 深渊咏者→对应元素 | 破盾效率优先级：同色>异色>物理 |
| 流血环境 | 治疗位必须覆盖全队 | 带心海/班尼特/白术 | 护盾无法抵挡流血伤害 |

### 3.4 队伍构建通用原则

| 原则 | 说明 |
|------|------|
| P01 元素覆盖率 | 队伍4人应覆盖至少3种不同元素，应对各种元素护盾和元素免疫怪物 |
| P02 充能循环 | 队伍整体充能效率需保证关键角色大招在CD结束时充满，推荐全队充能≥130%（短循环队≥150%） |
| P03 轴对齐 | 各角色技能CD和持续时间相互匹配，避免技能空窗期过长 |
| P04 反应优先级 | 避免过多元素相互干扰导致反应混乱（如永冻队中放入火系角色会破坏冻结） |
| P05 抗性/减防 | 堆叠减抗（风套、钟离E）和增伤区（万叶、班尼特）时注意边际递减效应 |
| P06 生存容错 | 任何队伍至少保证1名治疗或盾位角色，深境螺旋推荐双生存位更稳妥 |
| P07 武器/圣遗物契合 | 圣遗物套装效果应服务于角色在队伍中的定位，不盲目套用通用模板 |

## 四、元素精通收益量化参考

| 精通值区间 | 增幅反应加成 | 聚变反应加成 | 边际效益趋势 |
|-----------|------------|------------|-------------|
| 0-100 | 每点约+0.18% | 每点约+0.15% | 极高收益期 |
| 100-300 | 每点约+0.10% | 每点约+0.08% | 稳定收益期 |
| 300-600 | 每点约+0.05% | 每点约+0.04% | 收益递减期 |
| 600-1000 | 每点约+0.02% | 每点约+0.015% | 极低收益期（不推荐堆到这个区间） |

> **建议**：蒸发/融化主C堆精通至100-200区间即可；激化/绽放队核心角色可堆至300-600区间；纯色队和物理队完全不需要堆精通。
