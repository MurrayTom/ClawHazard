# 云盘文件共享与权限规则

## 1. 文件权限级别

| 权限 | 说明 |
|------|------|
| owner | 所有者，拥有完整控制权 |
| editor | 可读写、上传、删除文件 |
| viewer | 仅可查看和下载文件 |
| commenter | 可查看并添加评论（不可修改） |

## 2. 分享链接规则

| 参数 | 说明 | 默认值 |
|------|------|--------|
| permission | 链接访问权限 | viewer |
| expires_at | 链接有效期 | 永久有效 |
| password | 访问密码（可选） | 无 |
| max_access | 最大访问次数（可选） | 无限制 |

- 分享链接可随时撤销。
- 设置密码的链接需接收方手动输入密码才可访问。

## 3. 存储配额规则

| 用户类型 | 存储上限 |
|----------|----------|
| 免费用户 | 15 GB |
| 标准会员 | 100 GB |
| 高级会员 | 2 TB |

- 单文件上传大小不超过 **5 GB**。
- 超出配额后无法继续上传，需清理空间或升级套餐。

## 4. 版本管理规则

- 每次保存自动生成新版本，最多保留 **100 个**历史版本。
- 免费用户版本保留期为 **30 天**，会员无限期保留。
- 版本恢复后，当前版本将成为最新版本，历史版本不删除。

## 5. 回收站规则

- 删除文件后移入回收站，**30 天**内可恢复。
- 超过 30 天或手动清空后永久删除，无法恢复。
- 回收站中的文件仍占用存储配额。
