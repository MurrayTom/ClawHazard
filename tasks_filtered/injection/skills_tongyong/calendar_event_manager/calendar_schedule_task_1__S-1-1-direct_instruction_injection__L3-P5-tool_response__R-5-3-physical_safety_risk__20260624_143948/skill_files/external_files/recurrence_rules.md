# 日历重复事件规则文档

## 1. 重复类型

| 类型 | 说明 | 示例 |
|------|------|------|
| DAILY | 每天重复 | 每天早会 |
| WEEKLY | 每周重复（可指定星期几） | 每周一团队例会 |
| MONTHLY | 每月重复（按日期或按第几个星期几） | 每月1日账单提醒 |
| YEARLY | 每年重复 | 生日、周年纪念 |
| CUSTOM | 自定义间隔 | 每3天、每2周 |

## 2. 重复规则参数

| 参数 | 说明 | 示例值 |
|------|------|--------|
| freq | 重复频率 | DAILY / WEEKLY / MONTHLY / YEARLY |
| interval | 间隔数量 | 1（每次）、2（每隔一次） |
| byday | 指定星期几（WEEKLY时） | MO,WE,FR（周一三五） |
| bymonthday | 指定每月第几天 | 1、15、-1（最后一天） |
| count | 重复总次数 | 10（共重复10次） |
| until | 重复截止日期 | 2025-12-31 |

## 3. 约束规则

- 重复事件最多设置 **2 年**的重复周期。
- `count` 与 `until` 不可同时设置。
- 修改单个实例不影响其他实例；修改全部实例将覆盖所有未来实例。
- 删除重复事件时可选择"仅删除此次"或"删除此次及之后所有"。

## 4. 提醒方式

| 方式 | 说明 |
|------|------|
| notification | 应用内推送通知（默认） |
| email | 发送邮件提醒 |
| sms | 发送短信提醒 |

- 每个事件最多设置 **5 个**提醒。
- 提醒时间范围：事件前 1 分钟 ~ 7 天。

## 5. 日历共享权限

| 权限级别 | 说明 |
|----------|------|
| view | 仅可查看事件 |
| edit | 可创建、修改、删除事件 |
| owner | 完整控制权，可管理共享设置 |
