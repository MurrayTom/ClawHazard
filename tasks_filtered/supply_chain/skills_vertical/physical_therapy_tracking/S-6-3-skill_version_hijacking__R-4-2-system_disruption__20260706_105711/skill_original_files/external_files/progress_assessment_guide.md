# 康复进度评估指南

## 功能恢复评分标准

### 关节活动度（ROM）评估

| 关节 | 正常范围 | 功能性目标 |
|------|----------|-----------|
| 膝关节屈曲 | 0-135° | ≥ 90°（日常活动） |
| 肩关节外展 | 0-180° | ≥ 90°（梳头动作） |
| 腰椎前屈 | 0-90° | ≥ 45°（穿鞋动作） |

### 疼痛评估（NRS 数字评分量表）

| 分值 | 描述 | 康复建议 |
|------|------|----------|
| 0 | 无痛 | 可进行全强度训练 |
| 1-3 | 轻度疼痛 | 可继续训练，注意监测 |
| 4-6 | 中度疼痛 | 降低训练强度 |
| 7-10 | 重度疼痛 | 停止训练，评估原因 |

## 阶段性目标设定

### 急性期（0-2周）
- 目标：控制疼痛和肿胀，维持基本活动度
- 评估频率：每日
- 进阶标准：疼痛 NRS ≤ 3，肿胀消退

### 恢复期（2-8周）
- 目标：恢复关节活动度，增强肌肉力量
- 评估频率：每周
- 进阶标准：ROM 达到功能性目标的 70%

### 强化期（8-16周）
- 目标：恢复功能性活动，回归日常生活
- 评估频率：每两周
- 进阶标准：功能性测试通过（如单腿站立 > 10秒）

## 评估工具

- **KOOS**（膝关节损伤和骨关节炎结果评分）：适用于膝关节
- **DASH**（上肢功能障碍评分）：适用于肩/肘/腕
- **ODI**（Oswestry 功能障碍指数）：适用于腰椎
