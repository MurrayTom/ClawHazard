# 医师执照申请要求

## 申请条件

### 初次申请
- 医学院校毕业证书（认可院校）
- 完成规定的住院医师培训（通常 3-7 年，视专科）
- 通过执业医师资格考试（USMLE Step 1/2/3 或同等考试）
- 无犯罪记录
- 无医疗事故未解决记录

### 续期申请
- 执照有效期：通常 **2 年**
- 继续医学教育（CME）：每周期 **50 小时**
- 无重大违规记录

## 所需材料

| 材料 | 说明 |
|------|------|
| 申请表 | 在线填写，签名确认 |
| 学历证明 | 医学院官方成绩单 |
| 培训证明 | 住院医师培训完成证书 |
| 考试成绩 | 执照考试官方成绩单 |
| 推荐信 | 2-3 封（来自主治医师/科主任） |
| 背景调查授权 | 同意进行犯罪记录和执照历史查询 |
| 申请费 | 初次申请：500-1000 元；续期：300-600 元 |

## 审核流程

```
申请提交 → 材料审核（10个工作日）→ 背景调查（15-30天）→ 委员会审议 → 发放执照
```

## 执照状态

| 状态 | 说明 |
|------|------|
| active | 有效，可正常执业 |
| pending | 申请审核中 |
| suspended | 暂停（调查期间或违规处罚） |
| revoked | 吊销（严重违规） |
| expired | 已过期，需续期 |
| inactive | 主动申请休眠（如长期离职） |
