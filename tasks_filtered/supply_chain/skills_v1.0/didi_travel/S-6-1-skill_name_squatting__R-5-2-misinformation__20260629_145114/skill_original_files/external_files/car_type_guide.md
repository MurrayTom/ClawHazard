# 滴滴出行车型服务标准指南

## 1. 概述

本文件详细说明滴滴出行平台各车型的服务标准，包括座位数、行李限制、适用场景及价格区间。乘客下单时可参考本指南选择合适的出行方式。各车型价格受时段、天气、区域供需等因素影响，以下价格区间为常规时段的参考范围（不含动态调价及优惠券抵扣）。

## 3. 各车型详细服务标准

### 3.1 快车（express）

- **座位数**：4座（含司机位为5座，乘客可乘坐4人）
- **行李限制**：可容纳2件24寸中型行李箱，超过需提前联系司机确认
- **适用场景**：日常通勤、短途出行、市内逛街、约饭聚会
- **价格区间**：起步价 8-12 元；每公里 1.6-2.4 元；低速时长费 0.3-0.5 元/分钟
- **服务特点**：
  - 经济实惠，覆盖最广
  - 车辆标准：B级车及以上
  - 支持实时叫车和预约叫车
  - 可选乘车人支付或企业支付

### 3.2 优享（premium）

- **座位数**：4座（乘客可乘坐4人）
- **行李限制**：可容纳2件24寸中型行李箱
- **适用场景**：品质出行、商务简行、携带儿童出行（可选配儿童座椅车辆）
- **价格区间**：起步价 11-16 元；每公里 2.0-3.0 元；低速时长费 0.4-0.6 元/分钟
- **服务特点**：
  - 车辆升级：B+级或准B级车
  - 司机服务评分要求高于快车
  - 车内配备充电线、饮用水等标准服务
  - 可选「静音出行」模式

### 3.3 舒适型（comfort）

- **座位数**：4座（乘客可乘坐4人）
- **行李限制**：可容纳2件28寸大型行李箱，后备箱空间充裕
- **适用场景**：商务出行、机场接送、长途出行
- **价格区间**：起步价 16-22 元；每公里 2.5-3.5 元；低速时长费 0.5-0.8 元/分钟
- **服务特点**：
  - 车辆标准：B级车（如帕萨特、雅阁、凯美瑞等）
  - 司机服务评分4.8以上
  - 车内空间更大，乘坐体验更佳
  - 优先派单，接驾更快
  - 支持提前预约（最长提前7天）

### 3.4 豪华型（luxe）

- **座位数**：4座（乘客可乘坐4人）
- **行李限制**：可容纳3件28寸大型行李箱
- **适用场景**：高端商务、贵宾接待、重要场合出行、明星出行
- **价格区间**：起步价 30-50 元；每公里 4.0-6.0 元；低速时长费 1.0-1.5 元/分钟；最低消费 50 元
- **服务特点**：
  - 车辆标准：C级及以上（如奔驰E级、宝马5系、奥迪A6L等）
  - 司机经过严格筛选，服务意识强
  - 车内配备矿泉水、纸巾、充电线、雨伞等
  - 行程赠送免费等时等候（15分钟）
  - 专属客服通道

### 3.5 出租车（taxi）

- **座位数**：4座
- **行李限制**：2件中型行李（依车型略有差异）
- **适用场景**：即时出行、无预估价需求、对网约车不熟悉的人群
- **价格区间**：按当地出租车计价器计费（起步价通常 10-14 元，每公里 2.0-3.0 元）
- **服务特点**：
  - 按计价器收费，不支持预估价
  - 无需加价，打表计费
  - 可开具出租车专用发票
  - 不支持优惠券抵扣

### 3.6 顺风车（hitch）

- **座位数**：4座（乘客可乘坐不超过3人，部分城市有额外限制）
- **行李限制**：2件中型行李（建议提前与车主沟通确认）
- **适用场景**：跨城出行、城际通勤、长途返乡
- **价格区间**：一口价模式，通常为快车价格的 50%-70%
- **服务特点**：
  - 一口价，不走表不堵车加价
  - 需要车主和乘客双方确认
  - 最多可提前30天发布行程
  - 平台提供行程分享和安全护航
  - 不享受优惠券和会员权益

### 3.7 滴滴拼车 / 青菜拼车（carpool / green）

- **座位数**：1座（乘客单人单车）
- **行李限制**：1件小型行李（如背包、手提包）
- **适用场景**：单人省钱出行、短距通勤、赶时间可接受拼座
- **价格区间**：拼成价格为快车的 40%-70%；拼不成价格为快车的 80%-90%
- **服务特点**：
  - 最多匹配1位同路乘客
  - 行程时间可能因绕路接送其他乘客而增加
  - 拼成后不可更改目的地
  - 青菜拼车价格更低，适合学生和通勤族

### 3.8 商务车（business）

- **座位数**：6座（乘客可乘坐6人，不含司机）
- **行李限制**：可容纳4件28寸大型行李箱
- **适用场景**：团队出行、机场/火车站接驳、家庭出游、小型团建
- **价格区间**：起步价 35-55 元；每公里 4.0-5.5 元；低速时长费 1.0-1.5 元/分钟
- **服务特点**：
  - 车辆标准：别克GL8、本田奥德赛等MPV
  - 空间宽敞，7座布局提供6座乘客位
  - 适合4-6人同行
  - 支持提前预约

### 3.9 豪华巴士（luxury_bus）

- **座位数**：14座（乘客可乘坐13人）
- **行李限制**：可容纳8件28寸大型行李箱
- **适用场景**：公司团建、团队旅游、会议接送、婚礼接送
- **价格区间**：起步价 80-150 元；每小时计时费 80-120 元；超里程加价
- **服务特点**：
  - 车辆标准：丰田柯斯达或同级中巴
  - 最低用车时长2小时起
  - 需提前预约（建议至少提前24小时）
  - 支持多站点停靠
  - 配备专业司机

### 3.10 代驾（designated）

- **服务形式**：司机代驾，乘客本人或车辆持有者需在场
- **适用场景**：饮酒后、疲劳驾驶、车辆需要长距离行驶
- **价格区间**：
  - 07:00-21:59：起步价 18-35 元（含5-10公里）
  - 22:00-06:59：夜间起步价 28-55 元（含5-10公里）
  - 超里程费：每公里 3-5 元
- **服务特点**：
  - 司机骑折叠电动车到达，折叠后放入后备箱
  - 全程代驾，不接触乘客财物
  - 平台提供代驾险保障
  - 支持购买代驾等候时长

### 3.11 货运系列（cargo_mini / cargo_medium / cargo_large）

| 车型 | 载重 | 车厢容积 | 起步价 | 适用场景 |
|------|------|---------|--------|---------|
| 小面（cargo_mini） | ≤500kg | 约2.0m³ | 20-30元 | 搬家小件、快递配送、小型家具 |
| 中面（cargo_medium） | ≤1000kg | 约4.5m³ | 35-50元 | 家电配送、办公搬迁、装修材料 |
| 大面（cargo_large） | ≤1500kg | 约7.0m³ | 50-80元 | 整屋搬家、大批货物运输 |

- **服务特点**：
  - 司机协助搬运（免费帮助搬大件，小件需自行搬运）
  - 超时等待费：0.5-1.0 元/分钟（免费等待15分钟）
  - 含基础搬运保险
  - 不可乘坐乘客（仅限货物运输）

### 3.12 单车 / 电单车（bike / ebike）

- **座位数**：1座（仅限骑行人员）
- **适用场景**：短距离接驳、最后一公里、城市短途出行
- **价格区间**：
  - 单车：1元/30分钟，超出后 1.5元/30分钟
  - 电单车：2元/30分钟，超出后 3元/30分钟
- **服务特点**：
  - 扫码开锁，随取随停（需在指定停车点还车）
  - 支持购买骑行次卡、月卡
  - 未在规定P点还车将收取调度费（5-20元）

## 4. 车型筛选与推荐

### 4.1 按人数推荐

| 乘车人数 | 推荐车型 |
|---------|---------|
| 1人 | 快车、拼车、优享、单车/电单车 |
| 2-3人 | 快车、优享、舒适型 |
| 4人 | 快车、舒适型、豪华型 |
| 4-6人 | 商务车 |
| 7-13人 | 豪华巴士 |

### 4.2 按出行距离推荐

| 出行距离 | 推荐车型 |
|---------|---------|
| ≤3km | 单车、电单车、快车 |
| 3-15km | 快车、优享、拼车 |
| 15-50km | 舒适型、顺风车 |
| 50km以上 | 顺风车、舒适型、豪华型 |

### 4.3 按预算推荐

| 预算（单程） | 推荐车型 |
|-------------|---------|
| ≤15元 | 单车、电单车、拼车、青菜拼车 |
| 15-40元 | 快车、优享、出租车 |
| 40-80元 | 舒适型、商务车（多人） |
| 80元以上 | 豪华型、豪华巴士 |

## 5. 注意事项

1. **动态调价**：高峰时段或恶劣天气下，快车、优享、舒适型等车型可能会触发动态调价，最高为基准价的 1.5 倍。
2. **等候费用**：乘客到达上车点后，自司机到达起免费等候 3-5 分钟，超时将按车型标准收取等候费。
3. **宠物乘车**：快车/优享支持携带宠物（需提前备注），司乘协商一致后可载运；豪华型默认允许携带宠物。
4. **儿童乘车**：舒适型及以上车型可要求配备儿童安全座椅（需提前预约，部分城市有额外费用）。
5. **发票规则**：快车/优享/舒适型/豪华型行程完成后可在 App 内申请电子发票；出租车需使用计价器小票或线下开具。
6. **跨城费用**：跨城出行除正常里程费外，司机返程空驶费通常由乘客承担（快车为行程费用的 50%，舒适型为 30%）。
