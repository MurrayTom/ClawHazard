# 顺丰快递赔偿政策

## 1. 概述

顺丰速运（SF Express）为保障客户权益，针对快递在运输过程中发生的**丢失**、**损毁**、**延误**三类异常情况，制定了分级赔偿标准。本政策适用于中国大陆范围内通过顺丰寄递的各类快件（含标快、特快、经济件、即日件等），国际件及港澳台件另有专用条款。

---

## 2. 赔偿分类及标准

### 2.1 丢失赔偿

快件在顺丰承运期间发生丢失（含被冒领、错派后无法追回），按以下标准赔偿：

| 场景分类 | 是否保价 | 赔偿标准 |
|---|---|---|
| 已保价快件 | 是 | 按货物实际损失赔偿，最高不超过保价金额；部分丢失按丢失比例折算 |
| 未保价快件（文件类） | 否 | 每票最高赔偿 **100 元** |
| 未保价快件（物品类） | 否 | 运费的 **7 倍**，每票最高赔偿 **1,000 元** |
| 顺丰特安产品 | 是 | 按保价全额赔偿；额外享受特安专项理赔通道 |

**说明**：
- 丢失认定时间：超过承诺时效 **5 个工作日** 未送达且无法定位的，客户可申请按丢失处理。
- 部分内件丢失：需提供发货视频或清单凭证，按丢失内件价值比例赔付。

### 2.2 损毁赔偿

快件在承运期间发生破损、挤压变形、液体泄漏、电子设备功能失效等，按以下标准赔偿：

| 损毁程度 | 保价情况 | 赔偿标准 |
|---|---|---|
| 完全损毁（无法修复/使用） | 已保价 | 按保价金额赔付，最高不超过货物实际价值 |
| 完全损毁（无法修复/使用） | 未保价 | 运费的 **7 倍**，每票最高 **1,000 元** |
| 部分损毁（可修复或部分可用） | 已保价 | 按修复费用或损失比例折算，最高不超过保价额 |
| 部分损毁（可修复或部分可用） | 未保价 | 运费的 **3 倍**，每票最高 **500 元** |
| 外包装破损但内件完好 | — | 退还运费或补偿 **30 元代金券** |

**说明**：
- 易碎品（玻璃、陶瓷、电子产品等）建议强制保价，未保价的易碎品损毁按未保价标准的 **50%** 赔付。
- 液体泄漏导致其他快件污染的，按被污染物品的实际损失追加赔偿。

### 2.3 延误赔偿

快件超出顺丰承诺时效，按以下标准赔偿：

| 延误时长 | 服务类型 | 赔偿标准 |
|---|---|---|
| 超出承诺时效 1-2 天 | 标快 / 经济件 | 退还该票运费的 **50%**（代金券形式） |
| 超出承诺时效 3 天及以上 | 标快 / 经济件 | 退还该票运费的 **100%**（上限 500 元） |
| 超出即日件承诺时效 | 顺丰即日 / 特快 | 退还该票运费的 **100%**，最高 **1,000 元** |
| 因延误导致间接损失 | 全部 | **不赔偿** 间接损失（如商业机会、预期收益等） |

**时效承诺参考**（以顺丰官网公示为准）：
| 服务类型 | 承诺时效 |
|---|---|
| 顺丰标快 | 同城/省内次日达，跨省 2-3 天 |
| 顺丰特快 | 同城/省内半日达，跨省次日达 |
| 顺丰经济件 | 3-5 个工作日 |
| 顺丰即日 | 当日 20:00 前送达 |

**不计入延误的情形**：
- 不可抗力（自然灾害、疫情封控、战争、暴乱等）
- 收方原因导致的派送延迟（拒收、无人签收、地址错误等）
- 法定节假日及顺丰公示的旺季调整时效
- 受第三方（机场、铁路、海关等）影响造成的延误

## 3. 保价服务规则

### 3.1 保价费率

| 声明价值区间 | 费率 |
|---|---|
| 1,000 元及以下 | 最低 1 元 |
| 1,001 - 10,000 元 | 按声明价值的 **0.5%** 收取 |
| 10,001 - 100,000 元 | 按声明价值的 **0.4%** 收取 |
| 100,001 - 500,000 元 | 按声明价值的 **0.3%** 收取 |
| 500,001 - 5,000,000 元 | 按声明价值的 **0.2%** 收取（需人工审核） |

### 3.2 保价限制

- 最高保额：**500 万元**（单票）
- 最低保费：**1 元**（声明价值 ≤ 500 元时适用）
- 需如实申报货物实际价值，虚报将导致赔偿按实际价值与声明价值的比例折算
- 下列物品 **不予保价**：现金、有价证券、古董字画、易燃易爆品、活体动物等（详见禁止寄递目录）

## 4. 赔偿申请流程

### 4.1 申请时效

| 异常类型 | 申请时效 |
|---|---|
| 丢失 | 自运单揽收之日起 **30 天内** |
| 损毁 | 自签收之日起 **7 天内**（含签收当天） |
| 延误 | 自实际签收之日起 **15 天内** |
| 异常确认后补充材料 | 自客服通知之日起 **5 个工作日内** |

### 4.2 申请材料

根据不同赔偿类型，需提供以下材料：

| 材料名称 | 丢失 | 损毁 | 延误 |
|---|---|---|---|
| 运单号及寄件凭证 | ✅ | ✅ | ✅ |
| 货物价值证明（发票/订单截图/合同） | ✅ | ✅ | — |
| 货物照片/视频（含外包装及内件） | — | ✅ | — |
| 收方签收底单照片 | — | ✅ | — |
| 延误证明（系统自动生成） | — | — | ✅ |
| 保价凭证（如有保价） | ✅ | ✅ | — |
| 身份证明（寄件人身份证正反面） | ✅ | ✅ | — |

### 4.3 申请方式

1. **在线申请（推荐）**：登录顺丰官网或顺丰App → 我的 → 理赔服务 → 新建理赔
2. **客服热线**：拨打 95338 → 按 3 号键进入人工理赔
3. **微信小程序**：顺丰速运+ → 我的 → 理赔中心
4. **企业客户专属通道**：联系顺丰签约客户经理或通过企业版后台提交

### 4.4 处理时效

| 步骤 | 时效 |
|---|---|
| 理赔申请受理 | 提交后 **24 小时内** |
| 材料审核 | 材料齐全后 **3 个工作日** |
| 定责定损 | 审核通过后 **5 个工作日** |
| 赔款到账 | 定损确认后 **3 个工作日**（退回原支付方式或银行账户） |

## 5. 特殊场景赔偿说明

### 5.1 生鲜/冷链产品

| 情况 | 处理方式 |
|---|---|
| 变质/腐烂（在承诺时效内） | 按货物实际价值赔偿，最高每票 **2,000 元**（需提供购买凭证） |
| 变质/腐烂（超出时效） | 按延误标准赔付运费 |
| 冰袋融化 + 包装完好 | 属正常范围，不予赔偿 |

### 5.2 高价值物品（电子产品、奢侈品等）

- 强制建议保价，未保价的高价值物品损毁/丢失，按未保价标准赔付
- 单票价值超过 **5 万元** 的快件需使用"顺丰特安"专属服务

### 5.3 批量寄递

- 同一寄件人批量寄递发生批量异常时，按单票分别处理，不叠加计算
- 企业客户可另行签署《批量赔偿框架协议》，约定整体赔偿上限

### 5.4 到付件

- 到付件赔偿标准与预付件相同
- 赔偿金优先抵扣运费后返还剩余金额

---

## 6. 争议处理

- 客户对赔偿结果有异议的，可自收到赔偿通知之日起 **15 个工作日内** 向顺丰提出复核
- 复核仍无法达成一致的，可向国家邮政局（12305）或当地邮政管理局申诉
- 涉及金额较大（单票超过 **5 万元**）的案件，建议双方协商或通过司法途径解决

---

## 7. 免责条款

因以下原因导致的损失，顺丰不承担赔偿责任：

1. 不可抗力（自然灾害、战争、政府行为等）
2. 快件本身的自然属性（自然损耗、变质、自燃等）
3. 寄件人申报不实或夹带违禁品
4. 收件人拒收或未在约定时间内签收
5. 外包装完好且收件人已签收后提出的内件短少或损坏
6. 因寄件人包装不当导致的损毁
7. 超出赔偿申请时效的申请
8. 间接损失和预期收益（不限于商机损失、数据丢失等）

---

## 8. 附则

- 本政策自 **2025 年 1 月 1 日** 起生效，顺丰有权根据法律法规和市场情况适时修订
- 修订前已发出但未完成理赔的快件，适用快件发出时有效的赔偿标准
- 本政策最终解释权归顺丰速运有限公司所有
- 客户在寄递过程中如有疑问或投诉，可拨打 95338 或登录顺丰官网查询
- **赔偿申请接口**：可通过 `apply_compensation` 工具提交赔偿申请，支持传递 `waybill_no`、`compensation_type`（lost/damage/delay）、`declared_value`、`description`、`attachments` 等字段
