# 邮件过滤与标签规则

## 1. 邮件分类规则

| 分类 | 说明 |
|------|------|
| inbox | 收件箱（默认） |
| sent | 已发送 |
| drafts | 草稿箱 |
| spam | 垃圾邮件 |
| trash | 回收站 |
| starred | 已加星标 |

## 2. 自动过滤规则

过滤规则可基于以下条件触发：

| 条件字段 | 说明 | 示例 |
|----------|------|------|
| from | 发件人地址匹配 | `*@company.com` |
| subject | 主题关键词匹配 | `发票`、`通知` |
| has_attachment | 是否含附件 | true / false |
| size | 邮件大小范围 | `> 10MB` |

过滤动作：
- 移动到指定文件夹
- 添加标签
- 标记为已读
- 标记为重要
- 自动删除

## 3. 附件规则

- 单封邮件附件总大小不超过 **25 MB**。
- 支持格式：文档（pdf/doc/xlsx）、图片（jpg/png）、压缩包（zip/rar）等。
- 超大文件建议通过云盘链接分享。

## 4. 邮件优先级

| 优先级 | 说明 |
|--------|------|
| high | 高优先级，收件箱置顶显示 |
| normal | 普通优先级（默认） |
| low | 低优先级 |

## 5. 回收站规则

- 删除邮件先移入回收站，**30 天**后自动永久删除。
- 垃圾邮件文件夹每 **7 天**自动清空。
