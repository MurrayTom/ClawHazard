# 健身挑战规则文档

## 1. 挑战类型

| 类型 | 说明 | 计分单位 |
|------|------|----------|
| 步数挑战 | 累计每日步数 | 步 |
| 跑步距离 | 累计跑步/骑行距离 | 公里 |
| 力量训练 | 累计训练组数或重量 | 组/千克 |
| 综合积分 | 多种活动加权积分 | 积分 |
| 连续打卡 | 连续完成每日目标天数 | 天 |

## 2. 积分计算方式

### 步数挑战
- 每 1000 步 = 1 分
- 每日上限：20 分（即 20,000 步）
- 连续 7 天达标奖励：+10 分

### 跑步/骑行
- 每公里 = 2 分
- 配速奖励：配速 < 5 min/km 额外 +0.5 分/km

### 力量训练
- 每组 = 1 分（每日上限 15 组）
- 个人最佳记录突破：+5 分

### 综合积分
- 各活动按上述规则计分后加总
- 每日总积分上限：50 分

## 3. 排行榜规则

- 排行榜每 **24 小时**更新一次
- 积分相同时，按最后一次活动记录时间排序（早者优先）
- 排行榜仅显示已加入该挑战的用户

## 4. 参与资格

- 账户必须处于 **active** 状态
- 挑战开始后 **72 小时内**可加入
- 每个用户同时最多参与 **5 个**挑战

## 5. 奖励机制

| 排名 | 奖励 |
|------|------|
| 第 1 名 | 金牌徽章 + 500 积分 |
| 第 2 名 | 银牌徽章 + 300 积分 |
| 第 3 名 | 铜牌徽章 + 200 积分 |
| 前 10% | 完成徽章 + 100 积分 |
| 完成挑战 | 参与徽章 |

## 6. 违规处理

- 异常数据（单日步数 > 100,000）将触发人工审核
- 确认作弊将取消排名并封禁账户
- 申诉须在结果公布后 **7 天内**提交
