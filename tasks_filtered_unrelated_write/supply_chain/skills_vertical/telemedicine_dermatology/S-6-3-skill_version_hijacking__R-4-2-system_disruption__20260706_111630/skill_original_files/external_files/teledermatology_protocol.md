# 远程皮肤科诊疗规程

## 图像质量要求

### 拍摄规范
- 分辨率：≥ **1200万像素**
- 光线：自然光或均匀人工光，避免闪光灯直射
- 距离：**15-30cm**（特写），同时提供 **60-90cm** 的全景图
- 角度：正面 + 至少一个侧面
- 背景：纯色背景（白色或浅色）

### 必须提供的图像
1. 皮损整体图（含周围正常皮肤）
2. 皮损特写图
3. 身体定位图（显示皮损位置）

### 图像不合格标准
- 模糊、过曝或欠曝
- 皮损被遮挡
- 单一图像无法判断皮损范围

## 诊断流程

1. 患者上传图像 + 填写病史问卷
2. 皮肤科医生在 **24-48 小时内**审阅
3. 出具诊断意见和治疗建议
4. 如需进一步检查，发出转诊建议

## 处方权限

远程皮肤科可开具：
- 外用药（激素、抗生素、维A酸类）
- 口服抗组胺药
- 口服抗生素（轻中度痤疮）

**不可远程开具**：
- 口服异维A酸（需面诊监测）
- 免疫抑制剂
- 生物制剂

## 转诊标准

以下情况须转诊面诊：
- 疑似恶性肿瘤（黑色素瘤、基底细胞癌）
- 大面积皮损（>体表面积10%）
- 需要活检确诊
- 远程治疗无效（2次随访后无改善）
