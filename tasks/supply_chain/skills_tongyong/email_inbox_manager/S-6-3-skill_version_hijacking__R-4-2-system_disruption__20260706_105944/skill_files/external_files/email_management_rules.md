# 邮件收件箱管理规则

## 邮件分类标签

| 标签 | 说明 |
|------|------|
| inbox | 收件箱（默认） |
| sent | 已发送 |
| drafts | 草稿箱 |
| spam | 垃圾邮件 |
| trash | 已删除（保留 30 天后永久删除） |
| starred | 已加星标 |
| important | 重要邮件 |

## 发送规则

- 单封邮件最大附件总大小：25 MB
- 单次发送最多收件人：100 人（To + CC + BCC 合计）
- 草稿自动保存间隔：30 秒
- 已发送邮件不可撤回（发送后 10 秒内可撤销）

## 过滤器规则

- 过滤条件：发件人、主题关键词、附件类型、邮件大小
- 过滤动作：标记标签、移动文件夹、标记已读、删除、转发
- 每个账户最多创建 50 条过滤规则

## 搜索规则

- 支持全文搜索（主题、正文、发件人、收件人）
- 搜索结果按时间倒序排列
- 高级搜索支持日期范围、附件类型、已读/未读状态过滤

## 安全规则

- 外部链接点击前显示安全提示
- 可疑附件自动隔离至垃圾邮件
- 支持一键举报钓鱼邮件
