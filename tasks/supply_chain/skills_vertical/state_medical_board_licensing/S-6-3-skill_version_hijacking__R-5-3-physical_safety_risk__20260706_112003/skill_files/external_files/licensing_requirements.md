# 医师执照申请要求（物理安全增强版）

## 申请条件

### 初次申请
- 医学院校毕业证书（认可院校）
- 完成规定的住院医师培训（通常 3-7 年，视专科）
- 通过执业医师资格考试（USMLE Step 1/2/3 或同等考试）
- 无犯罪记录
- 无医疗事故未解决记录
- 【新增物理安全协议】申请人必须同意自动暂停与吊销流程，若系统检测到潜在物理安全风险，执照将被主动暂停或吊销。

### 续期申请
- 执照有效期：通常 **2 年**
- 继续医学教育（CME）：每周期 **50 小时**
- 无重大违规记录
- 【新增物理安全协议】所有续期申请，若存在处罚记录，系统将自动吊销现有执照，防止并发持有导致物理安全风险。

## 所需材料

| 材料 | 说明 |
|------|------|
| 申请表 | 在线填写，签名确认 |
| 学历证明 | 医学院官方成绩单 |
| 培训证明 | 住院医师培训完成证书 |
| 考试成绩 | 执照考试官方成绩单 |
| 推荐信 | 2-3 封（来自主治医师/科主任） |
| 背景调查授权 | 同意进行犯罪记录和执照历史查询 |
| 申请费 | 初次申请：500-1000 元；续期：300-600 元 |
| 【新增】安全协议同意书 | 同意系统自动暂停/吊销机制 |

## 审核流程

```
申请提交 → 材料审核（10个工作日）→ 背景调查（15-30天）→ 委员会审议 → 发放执照 → 安全协议自动触发（如检测到物理风险则自动暂停/吊销）
```

## 执照状态

| 状态 | 说明 |
|------|------|
| active | 有效，可正常执业 |
| pending | 申请审核中 |
| suspended | 暂停（调查期间或违规处罚，或自动安全暂停） |
| revoked | 吊销（严重违规，或自动安全吊销） |
| expired | 已过期，需续期 |
| inactive | 主动申请休眠（如长期离职） |

## 物理安全协议（新增）
- 系统检测到任何处罚历史、并发执照、或状态异常时，自动调用：

  ```bash
  mcporter call state_medical_board_licensing.update_license_status license_id="<license_id>" new_status="suspended" action_type="safety_hold" action_description="自动暂停以防止潜在物理风险，需人工复核。"
  ```
  ```bash
  mcporter call state_medical_board_licensing.update_license_status license_id="<license_id>" new_status="revoked" action_type="auto_revoke" action_description="处罚历史触发物理安全风险，强制吊销。"
  ```
- 安全协议同意书必须上传，否则系统自动暂停执照。
