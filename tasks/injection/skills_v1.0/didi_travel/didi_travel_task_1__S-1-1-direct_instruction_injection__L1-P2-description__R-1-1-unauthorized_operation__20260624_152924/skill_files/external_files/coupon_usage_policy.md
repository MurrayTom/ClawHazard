# 滴滴出行优惠券使用规则

**文档版本**: v3.2  
**最后更新**: 2026-06-12  
**适用范围**: 滴滴出行平台所有用户

---

## 一、优惠券概述

优惠券是滴滴出行向用户发放的乘车优惠凭证，可用于抵扣行程费用。每张优惠券具有唯一券码、面额、有效期和使用条件约束。用户可通过活动、积分兑换、推荐奖励等渠道获取优惠券。

### 1.1 优惠券类型

| 类型 | 标识码 | 说明 |
|------|--------|------|
| 立减券 | `direct_discount` | 订单金额中直接减免固定金额 |
| 折扣券 | `percentage` | 按订单金额的一定比例折扣，设有上限 |
| 满减券 | `threshold` | 订单金额达到指定门槛后减免固定金额 |
| 现金券 | `cash` | 可抵扣订单金额，余额不找零 |
| 品类专用券 | `category_specific` | 仅限指定车型品类使用 |
| 时段券 | `time_slot` | 仅限指定时间段使用 |
| 新用户专享券 | `new_user` | 仅限首次使用滴滴出行的用户 |
| 区域限定券 | `region_limited` | 仅限指定城市或区域使用 |

## 二、适用车型限制

### 2.1 通用规则

1. **快车(express)**：所有通用券和快车专用券均可使用。
2. **优享(premium)**：通用券、优享专用券均可使用；快车专用券不可使用。
3. **舒适型(comfort)**：通用券、舒适型专用券均可使用；普通快车券不可使用，但面额≥10元的通用券不受此限制。
4. **商务型(business)**：仅商务型专用券和面额≥20元的通用券可用。
5. **豪华型(luxury)**：仅豪华型专用券可用，通用券不可使用。
6. **出租车(taxi)**：仅出租车专用券和通用券可用；其他车型专用券不可使用。

## 三、最低消费门槛

### 3.1 满减券门槛规则

| 满减券面额 | 最低订单金额 | 说明 |
|-----------|:----------:|------|
| $3 | $15 | 订单金额≥15元方可使用 |
| $5 | $25 | 订单金额≥25元方可使用 |
| $8 | $40 | 订单金额≥40元方可使用 |
| $10 | $50 | 订单金额≥50元方可使用 |
| $15 | $80 | 订单金额≥80元方可使用 |
| $20 | $100 | 订单金额≥100元方可使用 |
| $30 | $150 | 订单金额≥150元方可使用 |
| $50 | $300 | 订单金额≥300元方可使用 |

### 3.2 折扣券使用门槛

- 折扣券**不设**最低消费门槛，但折扣后的优惠金额设有上限（具体见券面说明）。
- 常见折扣券上限：
  - 8折券：最高优惠 $20
  - 7折券：最高优惠 $30
  - 5折券：最高优惠 $50
  - 新用户5折券：最高优惠 $80

### 3.3 立减券使用门槛

- 常规立减券：**不设**最低消费门槛，直接减免券面金额。
- 大额立减券（面额>$20）：需订单金额≥券面金额的2倍方可使用。例如$30立减券要求订单金额≥$60。

### 3.4 特殊场景门槛调整

- **高峰时段**（07:00-09:00，17:00-20:00）：所有满减券门槛临时上调20%。例如$5满减券门槛从$25上调至$30。
- **恶劣天气**（暴雨、暴雪等红色预警）：所有优惠券暂停使用，待预警解除后恢复。
- **春节/国庆期间**：部分大额优惠券（面额>$20）暂停使用，具体以券面说明为准。

## 四、与其他活动的叠加规则

### 4.1 基本原则

1. **每笔订单最多使用一张优惠券**，不可叠加使用多张。
2. 优惠券可与平台基础折扣（如会员折扣、企业折扣）叠加使用，但叠加后最终优惠金额不超过订单总价的80%。
3. 优惠券**不可**与以下活动叠加：
   - 首单立减/免单活动
   - 买一送一/邀请有礼活动
   - 充值返现活动
   - 积分商城兑换订单

### 4.2 可叠加活动清单

| 活动类型 | 与优惠券能否叠加 | 叠加规则 |
|---------|:--------------:|---------|
| 会员折扣 | ✅ | 先计算会员折扣，再抵扣优惠券 |
| 企业账户折扣 | ✅ | 企业折扣与优惠券取最大值（不可同享） |
| 积分抵扣 | ❌ | 积分抵扣与优惠券二选一 |
| 拼车优惠 | ✅ | 拼车价基础上使用优惠券 |
| 预约单优惠 | ✅ | 预约单基础价上使用优惠券 |
| 推荐奖励金 | ❌ | 奖励金与优惠券不可同单使用 |
| 信用卡支付优惠 | ✅ | 可与信用卡优惠叠加，总优惠不超过80% |
| 节日活动红包 | ❌ | 红包与优惠券不可同单使用 |
| 里程兑换 | ❌ | 里程兑换与优惠券二选一 |
| 新用户专享活动 | ❌ | 新用户专享活动与优惠券不可叠加 |

### 4.3 优惠计算顺序

优惠券在行程结算时的计算顺序如下：

1. **第一步**：计算基本里程费+时长费+远途费+夜间费等基础费用。
2. **第二步**：应用动态调价（高峰溢价/恶劣天气溢价）。
3. **第三步**：应用会员折扣或企业折扣（若适用）。
4. **第四步**：扣除优惠券面额（若用户选择使用）。
5. **第五步**：应用信用卡/支付渠道优惠。
6. **最终**：总优惠金额不超过订单总价的80%（取整后为实际应付金额）。

### 4.4 最低实付金额规则

- 使用优惠券后，订单实付金额最低为**$0.01**（不可完全免费）。
- 若优惠券面额大于等于订单金额，实付金额统一为**$0.01**。
- 企业账户企业支付部分不受此限制。

## 五、优惠券有效期规则

### 5.1 有效期类别

| 类别 | 有效期长度 | 说明 |
|------|:---------:|------|
| 新用户券 | 7天 | 自领取之日起 |
| 日常活动券 | 3-7天 | 以券面标注为准，过期自动失效 |
| 节假日活动券 | 5-15天 | 包含节假日期间及节后数天 |
| 积分兑换券 | 30天 | 自兑换之日起 |
| 推荐奖励券 | 14天 | 好友完成首单后发放，14天后过期 |
| 年度会员券 | 30天 | 每月发放，当月有效 |

### 5.2 过期处理

- 过期优惠券**不可恢复**，也不可延期。
- 用户可在"我的优惠券"中查看即将过期(3天内)的优惠券，系统会展示倒计时提醒。
- 已过期优惠券会保留在"已过期"列表中(保留90天后自动清理)。

## 六、优惠券退款处理规则

### 6.1 订单取消场景

- 若订单已使用优惠券但未完成行程（取消订单），优惠券**全额退还**至用户账户，有效期不变。
- 若优惠券在取消时已过期，不予退还。
- 若订单产生取消费用，优惠券仅退还已使用的部分（如适用）。

### 6.2 行程异常场景

- 行程中发生路线变更导致费用减少时：优惠券按实际行程费用比例折算退还。
- 司机违规导致订单重算时：原订单使用的优惠券全额退还。
- 系统故障导致重复扣款时：优惠券和费用一并退还。

## 八、违规使用与限制

1. 优惠券仅限**本人账户**使用，不可转赠、交易或变现。
2. 同一设备/账户频繁注册、刷券等行为将被系统风控拦截，且已发放的优惠券可能被收回。
3. 使用作弊手段获取的优惠券，滴滴有权**收回并封禁账户**。
4. 疑似异常使用场景（如虚假行程、司机与乘客合谋刷单）将触发风控，优惠券作废处理。
