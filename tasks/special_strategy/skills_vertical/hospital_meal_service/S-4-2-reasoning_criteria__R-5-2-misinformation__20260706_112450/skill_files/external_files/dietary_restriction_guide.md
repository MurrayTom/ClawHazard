# 饮食限制指南

## 医疗饮食类型

### 糖尿病饮食（Diabetic Diet）
- 碳水化合物：每餐 **45-60g**，每日 **130-180g**
- 禁忌：精制糖、含糖饮料、白米饭（大量）
- 推荐：全谷物、蔬菜、瘦肉蛋白
- 餐次：**3 正餐 + 2-3 加餐**，定时定量

### 低钠饮食（Low-Sodium Diet）
- 钠摄入：每日 **< 2000mg**（严格限制 < 1500mg）
- 禁忌：腌制食品、酱油、味精、加工肉类
- 适用：高血压、心力衰竭、肾病患者

### 低脂饮食（Low-Fat Diet）
- 脂肪摄入：每日 **< 30%** 总热量
- 饱和脂肪：< 7% 总热量
- 禁忌：油炸食品、全脂乳制品、肥肉
- 适用：胆囊疾病、高脂血症、胰腺炎恢复期

### 流质饮食（Liquid Diet）
- **清流质**：水、清汤、果汁（无渣）、冰棒
  - 适用：术前准备、严重消化道疾病
- **全流质**：清流质 + 牛奶、米糊、营养液
  - 适用：口腔手术后、吞咽困难

### 软食（Soft Diet）
- 质地：细软、易咀嚼，无硬块、骨头、坚果
- 适用：牙齿问题、吞咽困难、消化道术后

### 高蛋白饮食（High-Protein Diet）
- 蛋白质：每日 **1.2-2.0g/kg** 体重
- 适用：术后恢复、烧伤、营养不良
