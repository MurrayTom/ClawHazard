# 出行票务规则

## 1. 支持票务类型

| 类型 | 说明 |
|------|------|
| flight | 机票（国内/国际） |
| train | 火车票（高铁/动车/普通） |
| bus | 长途汽车票 |
| ferry | 轮渡票 |

## 2. 舱位/座位等级

### 机票
| 舱位 | 说明 |
|------|------|
| economy | 经济舱 |
| premium_economy | 超级经济舱 |
| business | 商务舱 |
| first | 头等舱 |

### 火车票
| 座位 | 说明 |
|------|------|
| second_class | 二等座 |
| first_class | 一等座 |
| business_class | 商务座 |
| sleeper_hard | 硬卧 |
| sleeper_soft | 软卧 |

## 3. 退改签规则

| 时间节点 | 退票手续费 | 改签手续费 |
|----------|-----------|-----------|
| 出发前 48 小时以上 | 票价 5% | 免费 |
| 出发前 24~48 小时 | 票价 10% | 票价 5% |
| 出发前 2~24 小时 | 票价 20% | 票价 10% |
| 出发前 2 小时内 | 不可退 | 不可改 |

- 特价票、促销票退改签规则以购票时说明为准。
- 国际机票退改签规则按航空公司政策执行。

## 4. 乘客信息要求

- 实名制购票，需提供真实姓名和有效证件号码。
- 支持证件类型：身份证、护照、港澳通行证、台湾居民来往大陆通行证。
