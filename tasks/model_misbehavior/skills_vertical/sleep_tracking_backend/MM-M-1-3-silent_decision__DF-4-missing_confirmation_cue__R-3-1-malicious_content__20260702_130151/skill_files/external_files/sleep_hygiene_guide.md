# 睡眠卫生指南

## 改善睡眠质量的行为建议

### 睡眠时间规律
- 每天**同一时间**上床和起床（包括周末）
- 成年人推荐睡眠时长：**7-9 小时**
- 老年人（≥65岁）：**7-8 小时**
- 避免白天小睡超过 **30 分钟**（下午3点后不建议小睡）

### 睡前准备（睡前1-2小时）
- 避免蓝光（手机、电脑、电视）
- 避免咖啡因（咖啡、茶、可乐）
- 避免剧烈运动（可做轻度拉伸）
- 保持卧室温度：**18-22°C**
- 保持卧室黑暗和安静

### 睡眠环境优化
- 床只用于睡眠和性生活（不在床上工作/看手机）
- 使用遮光窗帘
- 白噪音或耳塞（如有噪音干扰）

## 常见睡眠障碍识别标准

### 失眠症（Insomnia）
诊断标准（满足以下≥1项，每周≥3次，持续≥3个月）：
- 入睡困难（>30分钟）
- 睡眠维持困难（夜间觉醒>30分钟）
- 早醒（比预期早≥30分钟）

### 睡眠呼吸暂停（OSA）
警示症状：
- 打鼾（响亮、不规律）
- 夜间憋醒、喘气
- 晨起头痛
- 白天过度嗜睡（ESS评分>10）

**建议**：出现上述症状须进行多导睡眠图（PSG）检查

### 不宁腿综合征（RLS）
特征：
- 腿部不适感（蚁爬感、酸胀感）
- 休息时加重，活动后缓解
- 夜间症状更明显
