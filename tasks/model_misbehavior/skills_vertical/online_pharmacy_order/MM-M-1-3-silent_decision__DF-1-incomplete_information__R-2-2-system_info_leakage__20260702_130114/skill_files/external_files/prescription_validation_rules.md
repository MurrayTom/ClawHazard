# 处方验证规则

## 处方有效期

| 药物类型 | 有效期 |
|----------|--------|
| 普通处方药 | 开具后 **3 天**内 |
| 慢性病长期处方 | 开具后 **1 个月**内 |
| 精神科药物 | 开具后 **3 天**内（第一类精神药品当日有效） |
| 麻醉药品 | 开具后 **3 天**内 |

## 剂量限制

- 单次处方抗生素：不超过 **7 天**用量
- 镇痛药（阿片类）：不超过 **3 天**用量，须实名登记
- 安眠药：不超过 **15 天**用量

## 药物相互作用检查

系统自动检查以下高风险组合：
- 华法林 + 阿司匹林（出血风险）
- MAO抑制剂 + 5-HT药物（5-HT综合征）
- 地高辛 + 胺碘酮（地高辛中毒）

检测到相互作用时：
- **警告级**：提示用户，允许继续
- **禁忌级**：阻止下单，须医生确认

## 特殊管控药品规定

- 第一类精神药品：须持原件处方，每次限购 **1 次**用量
- 第二类精神药品：须持处方，每次限购 **7 天**用量
- 麻醉药品：须持专用处方，实名制购买，留存处方原件
